# وصف الواجهات لـv0
صمم نموذجًا تفاعليًا لتطبيق Android شخصي اسمه «دفتر الديون»، لإدارة «لي عنده» و«عليّ له»، بواجهة عربية RTL وMaterial 3. استخدم React وTypeScript وTailwind كمعاينة تصميمية، دون Backend أو تسجيل دخول.
استهدف جوال 360–430px وادعم 320px وتكبير النص. عند الكمبيوتر اعرض إطار جوال مركزي. أرقام إنجليزية، والمبالغ والهاتف LTR داخل RTL.
الهوية: خلفية #F5F7FB، بطاقات بيضاء، نص #18283B، رئيسي #174F79، أخضر للتحصيل وبرتقالي داكن للسداد مع نص وأيقونة. زوايا 16–24px وأهداف لمس 48px وخط Cairo ودعم داكن. لا رسوم زخرفية.

الشاشات والتنقل:
1. الرئيسية: اختيار شيكل/دولار، المتبقي لك وعليك، صافي الديون بنص، عدد المفتوحة والجزئية والمسدد بالكامل، آخر النشاط، إضافة دين.
2. الأشخاص: بحث بالاسم والهاتف، أرصدة كل عملة، مرشح المؤرشفين، إضافة شخص.
3. نموذج الشخص: الاسم مطلوب، هاتف وملاحظات اختياريان، حفظ.
4. تفاصيل الشخص: رصيد لكل عملة واتجاه، الديون، إضافة دين للشخص، تعديل وأرشفة.
5. الديون: بحث بالشخص والوصف، مرشحات عملة واتجاه وحالة وفترة، بطاقات الاسم والوصف والمتبقي والحالة والتاريخ، الملغاة بمرشح مستقل.
6. نموذج الدين: شخص، لي/علي، عملة، مبلغ، تاريخ، سبب مطلوب، ملاحظات. إضافة شخص ضمن التدفق ثم العودة للمسودة معه محددًا. هوية الدين ثابتة بعد أول دفعة.
7. تفاصيل الدين: الأصل والمدفوع والمتبقي والحالة والدفعات. تسمية «تسجيل تحصيل» للدين لي و«تسجيل سداد» للدين علي. تعبئة المتبقي لا تحفظ مباشرة. الملغاة واضحة وتظل في السجل.
8. نموذج الدفعة: الشخص والعملة ثابتان، المتبقي، مبلغ وتاريخ وملاحظات. التعديل يحتاج سببًا وعرض أثره.
9. النشاط: إنشاء وتعديل وإلغاء، الشخص والمبلغ والعملة والوقت، تفاصيل قبل وبعد والسبب.
10. الإعدادات: نسخة مشفرة واستعادة، المظهر واللغة ومعلومات التطبيق. النسخ عرض تصميمي وليس تنفيذًا فعليًا.
التنقل السفلي: الرئيسية والأشخاص والديون والإعدادات، وعنوان ورجوع للشاشات الفرعية.

القواعد:
- شيكل ودولار مستقلان بلا جمع أو تحويل.
- كل دفعة لدين محدد، والمتبقي = الأصل − الدفعات الفعالة.
- الحالة مشتقة: غير مسدد، جزئي، كامل.
- الصافي = المتبقي لك − المتبقي عليك داخل العملة؛ صفر لا يعني تسوية الديون المتعاكسة.
- الأموال بوحدات صغرى صحيحة، ومنزلتان كحد أقصى، بلا تقريب صامت.
- رفض الصفر والسالب وتجاوز المتبقي والتاريخ المستقبلي أو السابق للدين، وتخفيض الأصل تحت المدفوع.
- رسائل عربية بجانب الحقول، منع النقر المكرر، تأكيد فقد المسودة، حالات تحميل وخطأ وخالية.
- إلغاء الدين تصحيح خطأ تسجيل لا تنازل؛ يحتاج سببًا ويبين أثر إلغاء دفعاته.
- الأرشفة لا تسقط الديون. الحذف النهائي فقط لشخص بلا معاملات.
- تغيير عملة نموذج فيه مبلغ يحتاج تأكيدًا ولا يحول المبلغ.
- فصل ما حصّلته عن ما سددته.

بيانات تجريبية متسقة:
أحمد: لي 1000 شيكل، دفعتان 200 و300، المتبقي 500. عليّ له 150 شيكل، الصافي لك 350 شيكل.
أحمد: لي 200 دولار، دفعة 50، المتبقي 150 دولار مستقلًا.
شخصان آخران لعرض غير مسدد ومسدد كاملًا.
اربط التنقل والنماذج والتصفية والدفعات محليًا وحدث جميع الأرصدة فورًا. لا أزرار مضللة. سلّم كل الشاشات ومكونات قابلة لإعادة الاستخدام. المخرجات مرجع لكتابة Kotlin وCompose.
