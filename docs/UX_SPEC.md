# عقد الواجهة — المرحلة 5
## الاتجاه المختار
دفتر مالي واضح مع انتقال سريع للأشخاص. الاتجاهات البديلة سبق تقييمها: دفتر واضح 0.60، أشخاص أولًا 0.30، خط زمني 0.10. هذه تقديرات ملاءمة وليست احتمالات إحصائية.

## التنقل
أربعة أقسام: الرئيسية، الأشخاص، الديون، الإعدادات.
الصفحة الفرعية تظهر رجوعًا. زر Android يرجع إلى الصفحة السابقة، ولا يفقد نموذجًا معدّلًا دون تأكيد.

## الشاشات
1. الرئيسية: اختيار شيكل/دولار، المتبقي لك وعليك، صافي الديون بنص مفهوم، عدد المفتوحة والجزئية والمسدد بالكامل، آخر النشاط، إضافة دين.
2. الأشخاص: بحث بالاسم والهاتف، إظهار جميع أرصدة العملات للشخص بدون جمع، اختيار عرض المؤرشفين، إضافة شخص.
3. نموذج الشخص: الاسم مطلوب، الهاتف والملاحظات اختياريان، حفظ واحد.
4. تفاصيل الشخص: رصيد لكل عملة واتجاه، الديون المرتبطة، إضافة دين مع تحديد الشخص تلقائيًا، تعديل/أرشفة عبر قائمة واضحة.
5. الديون: بحث بالشخص والوصف، تصفية بالعملة والاتجاه والحالة والفترة، الديون الملغاة بمرشح مستقل. المفتوحة تشمل غير المسددة والجزئية.
6. نموذج الدين: شخص، اتجاه، عملة، مبلغ، تاريخ، وصف مطلوب، ملاحظات. خيار إضافة شخص داخل التدفق يحفظ مسودة الدين ثم يعيد الشخص الجديد محددًا.
7. تفاصيل الدين: الأصل والمدفوع والمتبقي، الحالة، الدفعات بما فيها الملغاة مميزة بنص، تعديل وقائمة الإلغاء. التحصيل للدين لك والسداد للدين عليك. إخفاء إضافة دفعة عند السداد الكامل.
8. نموذج الدفعة: الشخص والعملة ثابتان، المتبقي ظاهر، مبلغ وتاريخ وملاحظات، تعبئة المتبقي بزر ثم حفظ. لا يسجل الزر دفعة مباشرة.
9. سجل النشاط: إنشاء وتعديل وإلغاء، اسم الشخص والعملة والمبلغ، وقت التسجيل؛ تفاصيل التعديل تظهر قبل وبعد والسبب.
10. الإعدادات: إنشاء نسخة مشفرة واستعادة، شرح كلمة مرور النسخة وإصدار التطبيق. لا حساب أو تسجيل دخول.

## قواعد الإدخال
- اللغة عربية وRTL مع عزل الأرقام والهاتف اتجاهيًا LTR.
- قبول أرقام عربية وإنجليزية، العرض أرقام إنجليزية بمنزلتين.
- عند تغيير عملة نموذج دين به مبلغ: سؤال واضح لتأكيد تغيير العملة؛ لا تحويل تلقائي.
- الخطأ ملاصق للحقل ونص عربي محدد؛ لا عرض stack trace أو اسم كود داخلي.
- تعطيل حفظ أثناء التنفيذ، مع الاحتفاظ بالمسودة وoperationId عند فشل قابل لإعادة المحاولة.
- التاريخ حتى اليوم، والدفعة لا تسبق الدين.
- النماذج قابلة للتمرير عند ظهور لوحة المفاتيح، وزر الحفظ لا يغطي آخر حقل.

## العمليات الحساسة
- تعديل دفعة: سبب مطلوب، يعرض أثر التعديل قبل التأكيد.
- إلغاء دفعة: يعرض المتبقي الجديد، سبب مطلوب.
- إلغاء دين: رسالة صريحة أنه تصحيح تسجيل لا تنازل؛ تعرض عدد الدفعات التي ستلغى والتأثير المالي، سبب وتأكيد.
- أرشفة شخص: لا تسقط ديونه؛ يتاح تحصيلها وسدادها، ولا تنشأ له ديون جديدة حتى إلغاء الأرشفة.
- صافي صفر مع ديون مفتوحة: عبارة صافي صفر، مع عدد الالتزامات المفتوحة. لا كلمة تمت التسوية.

## الوصول والتصميم
Material 3، خلفية هادئة، بطاقات أرصدة، زوايا 16–24dp، أهداف لمس 48dp، تباين مقروء، لا اعتماد على اللون وحده، دعم تكبير الخط وTalkBack.
لا رسوم زخرفية في الرئيسية، ولا منحنى يدعي حساب الثروة أو الربح.
في 320dp يعاد ترتيب المحتوى ولا يصغر النص لإجباره على الملاءمة.

## حالات التشغيل
حالة خالية لكل قائمة مع دعوة إضافة؛ تحميل واضح؛ فشل مع إعادة محاولة؛ نجاح الحفظ يفتح السجل المحفوظ ويحدث Flow.
التطبيق يبدأ فارغًا؛ بيانات أحمد في المعاينة خيالية وليست بيانات إنتاج.

## المعاينة
معاينة داخل المحادثة وليست تطبيق Android. تسمح بتجربة تحصيل جزئي وكامل وتبديل العملة. نماذج إضافة الشخص والدين لا تحفظ، وأزرار النسخ معطلة لأنها لم تنفذ.
فحص JavaScript syntax متاح؛ تعذر فحص المتصفح الفعلي لعدم توفر Chromium، لذا لا يوجد اعتماد بصري نهائي.

## بوابة Compose
تجميع المشروع، اختبار RTL وتكبير الخط وTalkBack ولوحة المفاتيح على جهاز/محاكي، واختبار تحديث جميع الشاشات بعد تعديل أو إلغاء دفعة.
