# دفتر الديون — Android 0.1.0
مشروع Android Native شخصي، Room + Kotlin + Compose، شيكل ودولار مستقلان. التطبيق يبدأ بلا بيانات تجريبية، ولا يطلب صلاحية الإنترنت أو التخزين أو جهات الاتصال.

## فتح وتشغيل
1. فك الحزمة وافتح مجلد DebtLedgerAndroid في Android Studio.
2. اختر JDK 17 لـGradle وثبت SDK Platform 35 وBuild Tools 35.0.0.
3. انتظر Gradle Sync ثم اختر جهازًا/محاكيًا Android 8 (API26) أو أحدث واضغط Run.
4. يبدأ التطبيق فارغًا. أضف شخصًا ثم دينًا ثم دفعة.
تنزيل أدوات البناء والمكتبات يحتاج الإنترنت أول مرة؛ الاستخدام اليومي محلي.

## أوامر Windows PowerShell
```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
.\gradlew.bat connectedDebugAndroidTest
```
الأمر الثاني يحتاج جهازًا أو محاكيًا متصلًا. APK عند app/build/outputs/apk/debug/app-debug.apk.

## أوامر Linux/macOS
```bash
./gradlew testDebugUnitTest assembleDebug
./gradlew connectedDebugAndroidTest
```

## النطاق
الرئيسية، الأشخاص، تفاصيل الشخص، الديون والتصفية، إضافة/تعديل شخص ودين ودفعة، إلغاء الدفعات والدين مع سجل تصحيح، أرشفة وإلغاء أرشفة، سجل النشاط، إعدادات توضح حدود الإصدار.
البيانات في ملف Room داخل مساحة التطبيق. إلغاء تثبيت التطبيق أو مسح بياناته يحذف الملف. نسخ Android التلقائي معطل عمدًا. النسخ المشفر والاستعادة لم تنفذ بعد؛ لا تعتمد هذه النسخة وحدها لحفظ سجلاتك الحقيقية.
UI الحالية تنفيذ أولي وظيفي يحتاج مراجعة بصرية على جهاز. وصف v0 في docs/V0_PROMPT_AR.md مرجع لتطوير المظهر.

## حدود معروفة
لا تشفير لقاعدة البيانات نفسها ولا قفل بيومتري بعد. سبب تعديل الدفع محفوظ، وسجل التدقيق ليس مقاومًا لتلاعب خارجي.
بعض النصوص العربية داخل Compose مباشرة؛ تحويلها إلى strings.xml وتنقيح الوصول مطلوبان قبل إصدار نهائي.
تبقى مراجعة لوحة المفاتيح وتكبير الخط وRTL وTalkBack والجهاز الفعلي بوابة اعتماد.
راجع BUILD_REPORT.md للنتيجة الفعلية للبناء والاختبارات، دون افتراض نجاح غير مسجل.
